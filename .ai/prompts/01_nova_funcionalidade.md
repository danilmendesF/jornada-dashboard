# 💬 PROMPT 01: NOVA FUNCIONALIDADE (SDD Standard)

Copie e envie o prompt abaixo quando desejar solicitar o desenvolvimento de uma nova funcionalidade:

---

```markdown
@IA Atue como Spec-Architect no projeto Jornada Dashboard.

Preciso implementar a seguinte nova funcionalidade:
[DESCREVA AQUI A FUNCIONALIDADE QUE DESEJA]

Siga o protocolo SDD:
1. Consulte o índice RAG `.ai/PROJECT_INDEX.md` para identificar os módulos envolvidos em `js/`.
2. Crie uma especificação em `.ai/specs/SPEC_XXX.md` seguindo o template oficial.
3. Crie o plano `implementation_plan.md` com as mudanças por módulo, resumo das decisões e plano de testes.
4. PARAR E AGUARDAR minha aprovação explícita antes de editar qualquer código.
```
